# IbrahimCart.github.io

Personal portfolio for Ibrahim Cartan. Live at **https://ibrahimcart.github.io**.

## Updating projects

All content lives in `projects.js`. To add a project, copy one `{ ... }` block in `PROJECTS`, fill it in, then commit and push. GitHub Pages redeploys automatically within a minute or two.

- `status`: `"complete"`, `"in-progress"` or `"planned"`
- `course`: used for the filter buttons (for example `"TCSS 490"`)
- `repo` / `demo`: optional links; leave as `""` to hide them

## Files

- `index.html`: page structure
- `styles.css`: styling, with light and dark mode
- `main.js`: renders the profile and project cards
- `projects.js`: **your content**
